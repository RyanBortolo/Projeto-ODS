# **App Name**: Vôlei na Quebrada

## Core Features:

- Informational Page Display: Render key sections like 'Sobre Nós' and general project information.
- Visual Media Gallery: Display images and videos showcasing training sessions and events.
- Direct Contact (WhatsApp): Provide a prominent, functional link for users to initiate contact via WhatsApp.
- Social Media Linkage: Integrate links to Instagram and TikTok profiles for community engagement.
- AI-Powered Content Suggestion Tool: An internal tool to generate inspiring text for news, event descriptions, or social media posts, leveraging project goals and community values.

## Style Guidelines:

- Primary color: Deep Ocean Blue (#0033a0), symbolizing trust and stability, serving as a foundational and strong element in the UI. (HSL: 222, 100%, 31%)
- Background color: Soft Sky (#D9DEE7), a very light, desaturated blue providing a clean and calming canvas that visually expands the layout. (HSL: 222, 18%, 93%)
- Accent color: Vibrant Cerulean (#4ADBF0), an energetic blue used for call-to-action buttons, links, and highlights, drawing the eye to important interactions. (HSL: 192, 85%, 65%)
- Body and headline font: 'PT Sans' (sans-serif), chosen for its modern aesthetic combined with a humanist touch, ensuring readability and approachability for all content.
