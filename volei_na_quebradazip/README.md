# Vôlei na Quebrada - Carapicuíba

Este é o ambiente de desenvolvimento do projeto **Vôlei na Quebrada**.

## 🚀 Como Colaborar

1. **Identificação do Projeto**: Na lista de projetos do Google/Firebase, este projeto pode aparecer com o ID: **`studio-137312140-79145`**. Peça para os colaboradores clicarem neste ID caso não vejam o nome "Vôlei na Quebrada".
2. **Acesso ao Studio**: Compartilhe a URL completa do seu navegador (a que termina em `/edit`) com os membros convidados.
3. **Preview do Site**: O site em desenvolvimento pode ser visualizado no painel lateral ou abrindo a URL de preview em uma nova aba.
4. **Design System**: Criamos uma página especial para exportação para o Figma em `/design-system`.
   - Use o plugin **html.to.design** no Figma e cole a URL do preview terminada em `/design-system`.

## 🛠 Troubleshooting (Erros de Acesso)

Se um membro for "Proprietário" ou "Editor" e ainda assim receber erro 403/Forbidden ou não ver o projeto:
- **Aceite do Convite**: O membro **precisa** abrir o e-mail de convite enviado pelo Firebase e clicar em **"Aceitar Convite"** antes de qualquer outra coisa. Sem isso, o projeto não aparece no Studio.
- **Conflito de Contas**: O navegador pode estar tentando acessar com outra conta Google logada (ex: e-mail pessoal vs profissional).
- **Solução**: Peça para o membro abrir o link do Studio em uma **janela anônima** e fazer login apenas com o e-mail que você convidou.
